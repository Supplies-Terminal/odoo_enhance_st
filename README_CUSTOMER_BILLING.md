# 客户账单自动生成功能

## 功能概述

这个功能用于在Odoo 15多公司环境下，自动为特定客户生成每日账单。当A公司下某客户的发票发生变化时，系统会自动在对应的公司中生成或更新账单。

## 主要特性

1. **客户-公司映射管理**：通过界面配置客户和对应公司的关系
2. **自动账单维护**：当发票创建/修改/删除时自动更新对应账单
3. **每日汇总**：按天汇总发票金额，生成对应的账单
4. **智能调整**：已付款账单通过调整单进行增减调整
5. **税务处理**：区分含税和不含税金额，自动计算税前金额

## 使用方法

### 1. 配置客户-公司映射关系

1. 进入 **ST > 客户账单映射** 菜单
2. 点击 **创建** 按钮
3. 填写以下信息：
   - **销售公司**：发票所属的公司（如：syntac）
   - **客户**：需要生成账单的客户（如：jo's tea）
   - **账单公司**：生成账单的目标公司（如：jo's tea公司）
   - **启用**：勾选以启用此映射关系

### 2. 系统自动处理

配置完成后，系统会在以下情况自动处理：

- **发票创建**：自动在对应公司创建当日账单
- **发票修改**：自动更新对应公司的账单金额
- **发票删除**：自动调整对应公司的账单金额

### 3. 账单生成逻辑

- **每日一张账单**：按发票日期生成对应的账单
- **金额分类**：区分含税和不含税金额
- **税前计算**：含税金额自动反向计算税前金额
- **调整机制**：
  - 未付款账单：直接修改现有账单
  - 已付款账单：创建调整单进行增减调整

## 技术实现

### 模型结构

- `customer.billing.mapping`：客户-公司映射关系表
- 扩展 `account.move` 模型，添加自动账单维护功能

### 关键方法

- `_update_customer_billing()`：主要的客户账单更新逻辑
- `_update_customer_billing_bill()`：更新或创建客户账单
- `_create_customer_billing_adjustment()`：创建调整单

### 触发时机

- 发票创建时（`create`）
- 发票修改时（`write`）
- 发票删除时（`unlink`）

## 注意事项

1. **产品配置**：确保目标公司中有以下产品：
   - `Customer Billing Products with TAX`：含税产品
   - `Customer Billing Products without TAX`：不含税产品

2. **科目配置**：确保产品配置了正确的收入和费用科目

3. **日记账配置**：确保目标公司配置了采购类型的日记账

4. **权限要求**：需要 `account.group_account_user` 权限来管理映射关系

## 示例场景

以您的需求为例：

1. **配置映射**：
   - 销售公司：syntac
   - 客户：jo's tea
   - 账单公司：jo's tea公司

2. **自动处理**：
   - 当syntac公司为jo's tea客户创建发票时
   - 系统自动在jo's tea公司中生成对应的账单
   - 按天汇总，区分含税和不含税金额
   - 自动计算税前金额

3. **持续维护**：
   - 发票的任何变化都会自动反映到对应账单
   - 确保两个公司的账目保持同步

## 故障排除

如果遇到问题，请检查：

1. 映射关系是否正确配置
2. 目标公司是否有必要的产品和科目配置
3. 系统日志中的错误信息
4. 权限设置是否正确
